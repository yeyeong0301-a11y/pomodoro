# 차근차근토닥토닥 뽀모도로
### 난독증 친화적 뽀모도로

## 핵심 기능: 난독증 관련
- 난독증 전용 한글 폰트 적용
- 읽기 가이드라인 기능: 더블 클릭시 텍스트가 강조됩니다.
- 단어 간격 조정 기능: 단어 간격과 자간/크기를 조절하여 개인에게 가장 잘 읽히는 지점을 설정할 수 있습니다.

## 기본 기능 관련
- 체크리스트 작업을 길게 누르면 작업명 수정 및 삭제 가능합니다.
- 배경색/세션 시간 및 횟수/진동, 음성 알림 등 그 외 기본 기능들은 전부 설정란에서 설정 가능합니다.
